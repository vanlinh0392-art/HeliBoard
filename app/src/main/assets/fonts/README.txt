Bundled Google Fonts

These fonts are bundled from the official google/fonts repository:
https://github.com/google/fonts

Included families:
- Be Vietnam Pro (OFL)
- Noto Sans (OFL)
- Open Sans (OFL)
- Lato (OFL)
- Montserrat (OFL)
- Inter (OFL)
- Nunito (OFL)
- Lexend (OFL)

Google Sans/Product Sans is not bundled because it is not distributed as an open-source Google Fonts family.
